# Уроки

- Тесты `tests/test_xray_config.py`: адрес моста берётся из вызова в том же тесте (`host="1.2.3.4"` в `test_build_client_config_split_routing`), а не из соседних тестов (`host="h"`).
- Мост в датацентре не воспроизводит путь телефона через оператора. DNS и скачивание с моста — только ориентир; решающая проверка — на телефоне.
- На маке владельца `/usr/bin/python3` отказан настройками, pytest не установлен. Тесты без фикстур гонять прямым вызовом функций из `python3.12`.
- Под Happ (JSON-подписка) DNS приложений задаёт «Tunnel DNS» Happ, не секция `dns` профиля (документация Happ). Секция `dns` действует на собственные запросы Xray.
- В Xray нет сопоставления IP → домен по кэшу DNS. Правило по домену видит только соединения с доменом (запрос или sniffing). Соединение по голому IP идёт по IP-правилам.
- Tencent отдаёт серверы WeChat почти одинаково для запросов из России и из Эстонии. Версию «чужой узел из-за DNS» проверять сравнением ответов с подсетью клиента (`dns.google/resolve?...&edns_client_subnet=`), не рассуждением.
- Правку профиля проверять на телефоне после переподключения Happ (выключить и включить), а не только после обновления подписки.
- Перед правкой — бесплатная проверка на устройстве (приложение с выключенным VPN), если она различает версии. Правка кода — после неё, не вместо.
