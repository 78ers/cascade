# Уроки

- Тесты `tests/test_xray_config.py`: адрес моста берётся из вызова в том же тесте (`host="1.2.3.4"` в `test_build_client_config_split_routing`), а не из соседних тестов (`host="h"`).
- Мост в датацентре не воспроизводит путь телефона через оператора. DNS и скачивание с моста — только ориентир; решающая проверка — на телефоне.
- На маке владельца `/usr/bin/python3` отказан настройками, pytest не установлен. Тесты без фикстур гонять прямым вызовом функций из `python3.12`.
